# Decision records

This directory contains short records for important project and documentation
decisions.

Use sequential filenames with a short kebab-case title:

```text
0001-short-decision-title.md
```

Use this structure:

```markdown
# 0001. Short decision title

## Status

Accepted

## Context

Explain the situation that led to the decision.

## Decision

Explain the decision that was made.

## Consequences

Explain what changes because of this decision.
```
